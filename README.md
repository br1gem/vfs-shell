# Эмулятор командной оболочки — вариант 15

Практическая работа по дисциплине «Конфигурационное управление».
Программа написана на Swift и запускается в терминале macOS.

## Этап 1: REPL

Программа многократно читает команды пользователя. Приглашение к вводу
содержит имя пользователя и компьютера, полученные из macOS.

Парсер разделяет команду и аргументы, поддерживает одинарные и двойные
кавычки, пробелы внутри кавычек и экранирование символов обратной косой
чертой.

Команды на этом этапе:

- `ls [аргумент]` — заглушка: выводит своё имя и аргумент.
- `cd [аргумент]` — заглушка: выводит своё имя и аргумент.
- `exit` — завершает программу.

Программа сообщает о неизвестной команде, неверном числе аргументов,
незакрытой кавычке и незавершённом экранировании. Параметров запуска
на первом этапе нет.

## Сборка и запуск

Требуется установленный Swift.

```sh
xcrun swiftc src/main.swift -o vfs-shell
./vfs-shell
```

Также можно запустить без отдельного шага сборки:

```sh
./run.sh
```

## Проверка


## Пример

```text
username@hostname:~$ cd "my folder"
cd: ["my folder"]
username@hostname:~$ unknown
Ошибка: неизвестная команда unknown
username@hostname:~$ exit
```

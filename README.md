# Эмулятор командной оболочки — вариант 15

Практическая работа по дисциплине «Конфигурационное управление».
Программа написана на Swift и запускается в терминале macOS.

## Этап 1: REPL

Программа многократно читает команды пользователя. Приглашение к вводу
содержит имя пользователя и компьютера, полученные из macOS.

Парсер разделяет команду и аргументы, поддерживает одинарные и двойные
кавычки, пробелы внутри кавычек и экранирование символов обратной косой
чертой.

Команды на этом этапе:

- `ls [аргумент]` — заглушка: выводит своё имя и аргумент.
- `cd [аргумент]` — заглушка: выводит своё имя и аргумент.
- `exit` — завершает программу.

Программа сообщает о неизвестной команде, неверном числе аргументов,
незакрытой кавычке и незавершённом экранировании. Параметров запуска
на первом этапе нет.

## Этап 2: конфигурация

При запуске поддерживаются параметры:

- `--vfs ПУТЬ` — путь к XML-файлу виртуальной файловой системы.
- `--script ПУТЬ` — путь к стартовому скрипту с командами эмулятора.
- `--config ПУТЬ` — путь к конфигурационному INI-файлу.

INI-файл содержит раздел `[emulator]` с параметрами `vfs_path` и
`script_path`. Пример находится в `examples/config.ini`. Значения
командной строки имеют приоритет над значениями INI-файла.
При запуске эмулятор выводит итоговые значения параметров.

Стартовый скрипт показывает каждую команду вместе с её результатом.
При первой ошибке выполнение прекращается с ненулевым кодом и
сообщением с номером строки. Если скрипт завершается без команды
`exit`, после него начинается интерактивный ввод.

```sh
./run.sh --config examples/config.ini \
  --vfs override.xml --script examples/startup_ok.txt
```

На втором этапе путь к VFS выводится для проверки настроек. Загрузка
XML-файла будет добавлена на третьем этапе.

## Сборка и запуск

Требуется установленный Swift.

```sh
xcrun swiftc src/main.swift -o vfs-shell
./vfs-shell
```

Также можно запустить без отдельного шага сборки:

```sh
./run.sh
```

## Пример интерактивной работы

```text
username@hostname:~$ ls "two words"
ls: ["two words"]
username@hostname:~$ cd folder
cd: ["folder"]
username@hostname:~$ ls a b
Ошибка: неверные аргументы команды ls
username@hostname:~$ unknown
Ошибка: неизвестная команда unknown
username@hostname:~$ cd "unfinished
Ошибка: незакрытая кавычка или незавершённое экранирование
username@hostname:~$ exit
```

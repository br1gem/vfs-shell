# Эмулятор командной оболочки — вариант 15

Практическая работа по дисциплине «Конфигурационное управление».
Программа написана на Swift и запускается в терминале macOS.

## Этап 1: REPL

Программа многократно читает команды пользователя. Приглашение к вводу
содержит имя пользователя и компьютера, полученные из macOS.

Парсер разделяет команду и аргументы, поддерживает одинарные и двойные
кавычки, пробелы внутри кавычек и экранирование обратной косой чертой.

- `ls [аргумент]` — пока заглушка: выводит имя и аргументы.
- `cd [аргумент]` — пока заглушка: выводит имя и аргументы.
- `exit` — завершает программу.

Программа сообщает о неизвестной команде, неверных аргументах,
незакрытой кавычке и незавершённом экранировании.

## Этап 2: конфигурация

Параметры запуска:

- `--vfs ПУТЬ` — путь к XML-файлу виртуальной файловой системы.
- `--script ПУТЬ` — путь к стартовому скрипту.
- `--config ПУТЬ` — путь к конфигурационному INI-файлу.

INI-файл содержит раздел `[emulator]` с ключами `vfs_path` и
`script_path`. Пример: `examples/config.ini`. Значения командной строки
имеют приоритет над значениями INI-файла. При запуске отображаются
итоговые значения параметров.

Стартовый скрипт показывает каждую команду и её результат. При первой
ошибке он останавливается с ненулевым кодом и сообщает номер строки.
Если скрипт выполнился без команды `exit`, затем начинается
интерактивный ввод.

```sh
./run.sh --config examples/config.ini \
  --vfs examples/multiple.xml --script examples/startup_ok.txt
```

## Этап 3: виртуальная файловая система

Источник VFS — XML-файл. Элемент `<vfs>` обозначает корень,
`<directory name="...">` — папку, а
`<file name="..." encoding="base64">` — файл с содержимым в Base64.
Папки могут содержать другие папки и файлы.

При запуске XML загружается в дерево объектов в оперативной памяти.
Содержимое файлов декодируется в байты. Исходный XML не изменяется и
не распаковывается на диск.

Команда `vfs-info` показывает загруженные папки, файлы и размер
содержимого файлов в байтах. Она служит для демонстрации загрузки VFS.
Команды `ls` и `cd` пока остаются заглушками; работа с каталогами VFS
будет добавлена на четвёртом этапе.

Примеры VFS:

- `examples/minimal.xml` — пустая файловая система.
- `examples/multiple.xml` — несколько файлов и папка.
- `examples/demo.xml` — вложенные папки более трёх уровней.

```sh
./run.sh --vfs examples/demo.xml \
  --script examples/startup_vfs.txt
```

Программа сообщает об ошибке, если XML-файл отсутствует, имеет
неверную структуру или содержит неверные данные Base64.

## Сборка и запуск

Требуются macOS и установленные инструменты Apple со Swift.

```sh
xcrun swiftc src/main.swift -o vfs-shell
./vfs-shell
```

Запуск без отдельного шага сборки:

```sh
./run.sh
```

username@hostname:~$ unknown
Ошибка: неизвестная команда unknown
username@hostname:~$ cd "unfinished
Ошибка: незакрытая кавычка или незавершённое экранирование
